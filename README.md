# Customer Data Analysis – SQL

## 📌 Project Overview
A SQL-based Customer Data Analysis project designed to analyze **customers, orders, agents, payments, and outstanding amounts**. The project uses SQL queries to extract business insights and answer practical customer and order management questions.

## 🛠️ Technologies Used
- SQL
- PostgreSQL / MySQL
- Relational Database Concepts

## 🔍 Key SQL Concepts Used
- INNER JOIN & LEFT JOIN
- GROUP BY & HAVING
- Aggregate Functions (`SUM`, `COUNT`, `MAX`)
- Subqueries
- Views
- Filtering with `WHERE`
- Date-based filtering
- `DISTINCT`
- Customer, order, and agent analysis

## 📊 Analysis Performed
- Analyzed customer orders and outstanding amounts
- Identified agents handling high-value orders
- Created a view combining orders, customers, and agents
- Analyzed customers by city
- Calculated orders handled by each agent
- Identified customers with high advance payments
- Analyzed outstanding amounts by city
- Identified highest-value orders
- Analyzed customers with more than two orders
- Performed date-based order analysis
- Identified agents handling multiple distinct customers

## 🎯 Objective
The objective of this project is to demonstrate practical SQL skills by transforming relational customer and order data into meaningful business insights using efficient queries.
